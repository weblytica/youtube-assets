## Project Naming Convention (Applied at End)
**Structure: Function » Project Type » Specific Name**

**Function Categories:**
- Marketing, Finance, HR, Sales, Admin, Operations, Technology, IT, Legal, Customer Service

**Project Type Categories:**
- Automation, Strategy, Analysis, Workflow, Documentation, Training, Assessment, AI

**Examples:**
- `Marketing » Documentation » GBP Post Guidelines`
- `Technology » AI » Claude AI Assistant Usage`
- `Sales » Automation » Lead Qualification System`

**Questions for Project Naming:**
1. Which Function category best describes this project's primary business area?
2. Which Project Type category fits the nature of this work?
3. What specific name clearly identifies this project?

*Note: If a needed Function or Project Type doesn't fit existing categories, I will alert you to consider adding new standardized options.*
